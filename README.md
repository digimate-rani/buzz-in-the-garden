# באזז בגינה

משחק טלפון: אתם דבורה בגינה. אוספים אבקה מפרחים, בונים רצפים של אותו צבע, מחזירים לכוורת והופכים אותה לדבש, ובורחים מצרעות. 10 שלבים, ובכל אחד מהם פרח פצצה שמפוצץ את כל הצרעות.

**לשחק:** https://digimate-rani.github.io/buzz-in-the-garden/

## להתקין על הטלפון (עובד גם בלי אינטרנט)

לפתוח את הקישור פעם אחת עם אינטרנט, ואז:

- **אייפון:** ב-Safari, כפתור שיתוף, ואז "הוספה למסך הבית".
- **אנדרואיד:** ב-Chrome, תפריט ⋮, ואז "התקנת אפליקציה".

מכאן המשחק נפתח מהאייקון, מסך מלא, גם במצב טיסה. השיא נשמר בטלפון.

## איך המשחק עובד

- גוררים אצבע בכל מקום על המסך, והדבורה זזה בעקבותיה.
- אותו צבע ברצף שווה יותר דבש. רצף של 6 ומעלה בהפקדה נותן בונוס "דבש טהור".
- צרעה שתופסת אתכם מפילה את כל השק.
- הכוורת מגינה מצרעות רק 10 שניות בכל המשחק. הטבעת סביבה מראה כמה נשאר.
- בכל יעד ניקוד (5,000, 8,000, 12,000 ...) פורח פרח פצצה: אספו אותו כדי לעלות שלב.

| שלב | ניקוד | מה חדש |
|---|---|---|
| 1 | 0 | הגינה מתעוררת |
| 2 | 5,000 | צרעות מהירות יותר ומגיעות בקצב גבוה יותר |
| 3 | 8,000 | שק של 12 מקומות, צבע כתום |
| 4 | 12,000 | קורי עכביש שמאטים את הדבורה |
| 5 | 16,500 | צבע לבן |
| 6 | 21,500 | הצרעה המזרחית, שמסתערת בקו ישר |
| 7 | 27,000 | שרב: פרחים נובלים מהר |
| 8 | 33,000 | לילה |
| 9 | 40,000 | שתי צרעות מזרחיות |
| 10 | 48,000 | גן המלכה |

## מבנה המאגר

| נתיב | מה זה |
|---|---|
| `src/buzz.html` | קוד המשחק. כאן עורכים. |
| `docs/` | האתר המוכן (נוצר מ-`src/buzz.html`). GitHub Pages מגיש את התיקייה הזו. |
| `build.py` | בונה את `docs/index.html` ו-`docs/sw.js` מחדש. Python בלבד, בלי התקנות. |
| `deploy/` | הגדרות לשרת משלכם: Caddy, nginx, וסקריפט העלאה. |

## עדכון המשחק

```bash
# לערוך את src/buzz.html, ואז:
python3 build.py
git add -A && git commit -m "עדכון" && git push
```

הטלפונים שהתקינו את המשחק מקבלים את העדכון לבד בפעם הבאה שהם פותחים אותו עם אינטרנט.

## הפעלה ראשונה של GitHub Pages (פעם אחת)

ב-GitHub: **Settings ← Pages ← Build and deployment**: Source: `Deploy from a branch`, Branch: `main`, תיקייה: `/docs`, ואז Save. אחרי דקה-שתיים הקישור למעלה עובד.

## אחסון בשרת משלכם (לא חובה)

הדומיין חייב להיות ב-https, אחרת הטלפון לא ישמור את המשחק לשימוש בלי אינטרנט.

1. להעתיק את `deploy/Caddyfile` ל-`/etc/caddy/Caddyfile` ולהחליף בו את `game.example.com` בדומיין שלכם.
2. `sudo systemctl reload caddy`
3. `./deploy/deploy.sh user@server-ip`

אם בשרת כבר יש nginx, להשתמש ב-`deploy/nginx.conf` ובהוראות שבראשו.
